# Browser Tetris

A minimal Tetris game that runs in your browser. No install or build step required.

## How to play

1. Open `index.html` in Chrome, Firefox, or Edge.
2. Use the arrow keys:
   - **← / →** — move left / right
   - **↑** — rotate
   - **↓** — soft drop (fall faster)
   - **R** — restart (also works after game over)

## Scoring

- **100 points** per line cleared
- The **Lines** counter shows how many rows you have cleared in total
